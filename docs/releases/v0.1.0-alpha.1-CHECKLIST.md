# ARKlinux v0.1.0-alpha.1 Release Checklist

## Completed proof

- [x] Static construction validation passes.
- [x] 48 Btrfs subvolumes defined and created.
- [x] 10 native A.R.K. process definitions validated.
- [x] `arklinux-kernel` constructed.
- [x] `initramfs-arklinux.img` constructed.
- [x] Raw GPT image constructed.
- [x] ARKESP contains kernel and initramfs.
- [x] ARKROOT identifies as ARKlinux.
- [x] QEMU UEFI boot demonstrated.
- [x] Operator login demonstrated.
- [x] Wayland/Labwc graphical scaffold demonstrated.
- [x] Raw image written to SanDisk Cruzer Glide.
- [x] USB write verified byte-for-byte against the raw image.
- [x] HP Z4 G4 bare-metal USB boot demonstrated.

## Required before publishing GitHub Release assets

- [ ] Commit/merge the complete full-construction source currently validated on the build host.
- [ ] Record the merged commit SHA used for the release.
- [ ] Re-run the structural image verifier against the final artifact.
- [ ] Record `sha256sum arklinux-x86_64.raw`.
- [ ] Compress `arklinux-x86_64.raw` with zstd.
- [ ] Split the compressed artifact into release-asset-sized parts.
- [ ] Generate `SHA256SUMS` for every uploaded part.
- [ ] Reconstruct the image from the split parts and verify it matches the original raw-image SHA-256.
- [ ] Create annotated tag `v0.1.0-alpha.1` at the exact merged release commit.
- [ ] Create a GitHub prerelease titled `ARKlinux 0.1.0-alpha.1 — First Bare-Metal Boot`.
- [ ] Upload `SHA256SUMS`, raw-image SHA file, and all compressed split image parts.

## Release-boundary warnings

- The graphical environment is still a scaffold, not the finished ARKlinux desktop.
- Aletheia developmental persistence is not complete.
- DREAMER/ID is not complete.
- Cube developmental/instinctive behavior is not complete.
- Temporary developer-preview authentication must not be represented as production security.
- Do not install to an internal production/NVMe target solely because this alpha boots from USB.
